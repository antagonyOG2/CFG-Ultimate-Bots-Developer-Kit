INSTALL (one time)
1. Extract this zip. You get a folder named CFG-Offline-Bots.
   Easiest: extract it straight into your Camp Forest Green game folder
   (the folder that contains Start_CampForestGreen.exe). Anywhere else also works.
2. Double-click INSTALL.bat.
   It finds Camp Forest Green on any drive (Steam libraries on any drive, or the
   CampForestGreenLauncher folder), puts the mod inside the game folder, checks every
   file, and creates a "CFG Offline Bots" shortcut on your Desktop and in the Start menu.

PLAY
1. Double-click "CFG Offline Bots" on your Desktop. No windows to answer, nothing to type.
2. When the game is up, open Offline Play once. The mod loads by itself a moment later; you can
   tell it is loaded when the extra setup rows (Counselor Bot Skill, Jason Difficulty, Match Length)
   appear. In a hosted lobby an "AI JASON" status line is shown in the top-right corner.
3. Play Offline, Online (host a lobby with your friends) or Challenges as usual.
   F1 adds a second AI Jason, F3 adds counselor bots.

Your saves are backed up automatically into CFG-Offline-Bots\Backups each time you launch
(the newest 10 are kept). The mod never changes Camp Forest Green's own files or saves.

UNINSTALL
Double-click UNINSTALL.bat in the CFG-Offline-Bots folder. It removes the shortcuts and the
mod folder (you can keep the save backups). Camp Forest Green itself is untouched.

IF SOMETHING GOES WRONG
- "Not inside your Camp Forest Green folder": run INSTALL.bat.
- "A mod file is missing": your antivirus probably removed it. Allow the CFG-Offline-Bots
  folder in your antivirus, extract the zip again and run INSTALL.bat.
- "Your Camp Forest Green version is not supported": the game was updated; the shortcut can
  start the game without the mod until a matching mod update is released.
- The mod did not load: make sure you opened Offline Play once after the game started.
  A log is saved in CFG-Offline-Bots\Diagnostics; send the newest Loader-*.txt with your report.
